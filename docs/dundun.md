# 盾盾：造型与动效

盾盾是 Notchkeeper 的原创吉祥物，放在刘海左耳、展开面板和卡片里，用表情告诉你现在是什么状态。本文是造型数据和动效规则的唯一依据，代码里的数字都应能在这里找到出处。

## 1. 几何

坐标用「画布单位」：画布原点在左上，+y 向下。

- 40pt 版：1 单位 = 2pt，画布 80 × 68pt = viewBox `-4 -6 40 34`，右上多留空间给装饰。
- 20pt 版（左耳）：1 单位 = 1pt，画布 28 × 28pt，原点 (0, 0)。

| 部件 | 数据 |
|---|---|
| 身体 | 正圆，圆心 (14, 16.5)，半径 10；竖直线性渐变，从上到下两色见第 2 节；没有描边、高光、阴影 |
| 眼睛中心 | 左 (10.5, 17)，右 (17.5, 17) |
| 墨色 | `#16171A`：眼睛、▲ 里的 !、气泡里的 ? |
| 右上装饰区 | x 18.5–28，y 0.5–8.5（40pt 的第三个 Z 例外：x 28.5–33.5，y −3.6–0.6）；不跟身体位移和旋转；不压身体圆 |
| 旋转 | 只转渐变和眼睛，绕身体圆心；圆本身不进旋转变换，免得轮廓抗锯齿变化 |

收起态左耳：盾盾的身体圆心 y = 刘海高 / 2；画布左缘 = 收起形状的左外边 + 外翻 4 + 6。右耳指示的圆心 x = 收起形状宽 − 17.5。都按刘海尺寸现算，不写死。

## 5. 动效

**原则：** 克制的幅度，活泼的节奏。每次只动一两个部件；进场稍慢、退场稍快；用弹簧和正弦缓动，不用线性。

**渲染：** 用 Core Animation。每个动作只在开始时提交一次动画，中间帧由系统合成器在 App 进程外插值。循环动作的帧率限在 30–60fps（`preferredFrameRateRange`，macOS 12 起可用），一次性动作不限（HANDOFF「已定决策」10-29）。看不见（窗口被遮挡、熄屏、锁屏）时撤掉全部动画，停掉时钟和犯困计时器。

| 场景 | 动作 |
|---|---|
| 呼吸（空闲常驻） | 以底部为锚点，scaleY 1→1.03、scaleX 1→0.99，周期 4.6s，正弦往返；睡着时改为 6s、scaleY 1.045 |
| 眨眼 | 眼睛 scaleY 1→0.1→1：闭眼 60ms（ease-in），睁眼 90ms（ease-out）；间隔 2.5–6s，15% 连眨两次 |
| 跟随鼠标 | 鼠标在 400pt 以内：眼睛最多偏 1.5 单位，身体最多倾斜 4°，弹簧 response 0.3、damping 0.85；鼠标停 4s 后眼睛慢慢回正。只有睁着眼的造型（空闲、工作、等你回答、两种警告）看鼠标。设置里可关（`config.json` 的 `dundunFollowsMouse`，默认开） |
| 鼠标到刘海上 | 「探头」：scale 1.06（弹簧），眼睛放大 1.1。和跟随鼠标一样，只有睁眼的造型做，关掉「跟随鼠标」也不做 |
| 空闲小动作 | 有盾盾在看鼠标时不做（鼠标在 400pt 以外动不算）；每 8–20s 一个，按权重抽，不连续重复：东张西望、歪头好奇、侧身探看、原地小跳（压 0.92 → 跳 2 单位 → 落地再压）、抖一抖（三次衰减）、偶尔转一圈（5%） |
| 完成 | 压扁 90ms → 跳 4 单位，空中转 360°（0.55s，ease-out）→ 落地压扁回弹 → 星星弹出 → 笑眼停住 |
| 工作 | 进场点一下头；循环 1 单位正弦浮动，周期 1.1s |
| 思考 | 歪头 6°；云里三个点依次明暗，周期 1.2s |
| 等你回答 | 歪头 −8°（弹簧）；气泡弹出，之后上下浮 1 单位，周期 2s |
| 出错 | 一缩（scale 0.94，下沉 1）；× 弹出；之后静止 |
| 警告 mismatch | 眼睛睁大；▲ 弹出，柔和闪两下后静止 |
| 危险 | 横向抖三下、逐次衰减（0.45s）后静止；右耳红点外圈 1.6s 柔和脉冲，循环 |
| 睡着 | 慢呼吸；Z 依次上浮并淡出 |
| 晕 | 摆锤 ±6°；螺旋眼转 |
| 被打断 | 下沉一下再回位，0.3s |
| stale | 静止，不透明度 0.85 |
| 换造型 | 渐变颜色交叉淡化 0.3s；眼形「眨眼换形」0.18s（压成线 → 换形 → 睁开） |
| 减弱动态效果 | 不位移、不缩放；颜色和眼形 0.15s 淡入淡出；只保留眨眼；危险脉冲环改为静止环 |

**造型优先级：** 守卫（danger、mismatch、stale）> 晕 > agent（working、question、error、finished……）> 睡着 > 空闲。断网、探针没结果这两种 unknown 不改造型，靠右耳灰环和文案表达。

**性能验收：** 刘海机型 120Hz 屏，收起空闲 60s，App CPU 平均 < 0.5%；鼠标持续移动 60s < 3%。用 `top -l 70 -s 1 -pid <pid>` 测，结果写进提交说明。
