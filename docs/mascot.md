# 盾盾：造型与动效

盾盾是 Notchkeeper 的原创吉祥物，放在刘海左耳、展开面板和卡片里，用表情告诉你现在是什么状态。本文是造型数据和动效规则的唯一依据，代码里的数字都应能在这里找到出处。

数字的一手来源是伪 3D 原型（分支 `prototype/dundun-3d` 的 `prototype/dundun-3d/main.swift`，用户 10-29 认可）；原型里没有的部分由用户 10-29 逐条确认。

## 1. 几何

### 画布

坐标用「画布单位」：画布原点在左上，+y 向下。

- 40pt 版：1 单位 = 2pt，画布 80 × 68pt = viewBox `-4 -6 40 34`，右上多留空间给装饰。
- 左耳不另画：是面板里的 32pt 盾盾（40pt 版的数据，1 单位 = 1.6pt）按 20/32 缩小（§5「收起与展开」）。

| 部件 | 数据 |
|---|---|
| 身体 | 正圆，圆心 (14, 16.5)，半径 10；竖直线性渐变，从上到下两色见第 2 节；没有描边、高光、阴影 |
| 眼睛静止中心 | 左 (10.5, 17)，右 (17.5, 17) |
| 墨色 | `#16171A`：眼睛、▲ 里的 !、气泡里的 ?、锁孔 |
| 右上装饰区 | 中心 (23.25, 4.5)；大致 x 18.5–28、y 0.5–8.5（40pt 的第三个 Z 例外，到 x 33.5、y −3.6）；不跟头转；不压身体圆 |

### 球面模型（二维图形模拟三维）

身体是一个半径 10 的球，眼睛贴在球面上。所有动作，包括跟随鼠标，都用**头的朝向**表达：

- yaw：左右转，正 = 脸朝右；pitch：上下点，正 = 抬头；roll：侧歪，正 = 顺时针。
- 眼睛按静止中心算出在球面上的经纬度：`lat = asin((ey − cy) / r)`，`lon = asin((ex − cx) / (r · cos lat))`。眼睛在赤道下方，所以从正前方往下转 lat（按上面的约定是 pitch = −lat），再左右转 lon。两只眼各偏离正中约 20°，所以正脸时眼宽是平面图的 cos 20° ≈ 0.94，这是三维的正常结果。
- 转到背面的眼睛不画。转 90° 时眼睛在轮廓边缘、宽度约 0；转 180° 看不见。
- **身体圆和渐变都不转**：光从上面来，转头只动眼睛。圆本身不进旋转变换，免得轮廓抗锯齿变化。
- 眼睛整体放大 ×1.35，以各自的静止中心为原点（§3 的数字是放大前的）。

图层树（Core Animation，从外到内）：

```
stage ─┬─ body（呼吸，锚点在身体底部）
       │   └─ disc（圆形遮罩，不转）
       │       ├─ 渐变
       │       └─ pose ⊃ yaw ⊃ pitch ⊃ roll ⊃ 左眼、右眼
       └─ 装饰
```

- pose、yaw、pitch、roll 都是 `CATransformLayer`。pose 放造型的静止朝向（§2），按先 roll、再 pitch、最后 yaw 合成（`CATransform3DConcat(CATransform3DConcat(roll, pitch), yaw)`）；yaw / pitch 给跟随鼠标，动作叠加（additive）在 yaw / pitch / roll 上。
- 眼睛图层的锚点在眼睛中心，`anchorPointZ = −半径`（球心），整层挪到圆心后按经纬度转到球面上；`isDoubleSided = false` 藏背面。
- 实测（翻转视图，`isFlipped = true`）：`rotation.y` 正 = 脸朝右，`rotation.x` 正 = 抬头，`rotation.z` 正 = 顺时针。

### 在刘海里的位置

收起态左耳：盾盾的身体圆心 y = 刘海高 / 2；画布左缘 = 收起形状的左外边 + 外翻 4 + 6。右耳宽 44，指示的中心 x = 收起形状宽 − 17.5。都按刘海尺寸现算，不写死。

## 2. 16 个造型

每个造型由五样东西组成：身体渐变、眼形（§3）、头的静止朝向、装饰（§4）、右耳指示。装饰分两类：

- **心情装饰（mood）**：角色的一部分（睡着的 Z、思考云、星星……）。收起时留在左耳盾盾身上。
- **告示（sign）**：出了什么事（×、▲!、沙漏、!!、锁、断网）。收起时挪到右耳当图标，左耳只留脸。展开后盾盾也不带它，出口状态由面板右上的徽章表达（用户 10-29 定面板版式，`docs/ui.md`「面板布局」）；设置页等别处的 40pt 盾盾照常带着。

### 右耳指示

右耳只有一个位置，和左耳显示同一个状态（不拆成网络 / agent 两条通道）：

- **告示图标**：sign 造型把装饰原样挂到右耳，1 画布单位 = 2pt（和 40pt 盾盾右上角的装饰一样大，约 14pt），装饰外框的中心对准右耳中心，循环节奏和面板里的一样（§5）。
- **点**：三蓝点 `#3B9EFF`，直径 3pt，圆心在中心 x − 8、− 3、+ 2；依次亮起（不透明度 0.35 → 1 → 0.35，各 0.25s，周期 1.2s，相邻错开 0.2s）。青点、青柠点直径 7pt。
- **灰色空心环** `#8E8E93`（7pt、1pt 描边）：探针没结果（probeFailed）。这种 unknown 不改造型，只在右耳表达，所以收起态的 unknown 不会被看成正常。它盖过 mood 造型的点，sign 造型的图标又盖过它（用户 10-29）。

### 优先级

几个状态同时成立时，画最高的那个（用户 10-29 确认）。多个会话时取最高的会话。

1. 守卫：danger / shielded（两者互斥）> mismatch > stale > offline
2. 晕
3. agent：approval > question > longTurn > working > finished
4. 睡着
5. 空闲

thinking、error、interrupted 暂不接线，不进优先级。

### 眼形补间

Core Animation 只在两条路径点数、结构完全相同时才能逐点补间，所以所有眼形都先化成同样的闭合多边形（照 [Flubber](https://github.com/veltman/flubber) 的做法）：

1. `CGPath.flattened(threshold: 0.004)` 拍平成折线。
2. 描边眼形先化成轮廓：中线按弧长重采样到 64 点，沿法线左右各偏半个线宽，两端各补 11 点的半圆头。
3. 按弧长等距重采样到 **120 点**闭合多边形。
4. 统一绕向（有向面积为负就反转）。
5. 旋转起点，让它和上一个形状对应点的平方距离之和最小，补间时不打转。

眨眼也是眼形补间：把睁眼多边形以自己的竖直中心为轴压到 0.1 倍高，再回来。

## 5. 动效

**原则：** 克制的幅度，活泼的节奏。每次只动一两个部件；进场稍慢、退场稍快；用弹簧和正弦缓动，不用线性（星星自转除外）。

**渲染：** 用 Core Animation。每个动作只在开始时提交一次动画，中间帧由系统合成器在 App 进程外插值。不设帧率上限，不给 `preferredFrameRateRange`，交给系统按屏幕刷新率合成（用户 10-29 选画面优先。取舍：Apple 建议能低就低以省电，120Hz 下常驻循环的合成功耗记在 WindowServer 上，`top -pid` 量不到）。看不见（窗口被遮挡、熄屏、锁屏）时撤掉全部动画，停掉时钟和犯困计时器。
- **身体圆盘（disc）显式按屏幕倍率栅格化**（10-30 实测）：头一转（yaw / pitch 不为 0），眼睛边缘就发软；展开时盾盾总在看刘海上的鼠标，所以用户看到「一展开眼睛就糊」。推断是三维子树拍平到 disc 时被重采样，机制没证实。
  - 量法：ScreenCaptureKit 截原生分辨率，身体内部（主要是眼睛）拉普拉斯绝对值前 10 个的均值 ÷ 亮暗差，越大越锐；这个数也会把锯齿算成「锐」，所以每种做法都放大 8 倍用眼看过。
  - 面板里收稳后：原来转头时约 0.5，不转头 1.36；眼睛自身的球面旋转换成单位矩阵、父层照转，0.55；眼睛自己的 `contentsScale` 提到 4x、去掉圆形遮罩，都没用。disc 按屏幕倍率栅格化 0.9–1.1。
  - 试过按两倍栅格化：面板约 1.5，但左耳要把位图缩小约 3.2 倍，`linear` 缩小出阶梯锯齿；加 `trilinear` 平滑了，面板却回到约 1.0，和一倍一样，白多 4 倍像素。按一倍时左耳只缩小 1.6 倍，`linear` 就是平滑的。
  - `shouldRasterize` 在这里是为了拍平的分辨率，不是为了缓存：眨眼、转头、常驻的头部循环（sleeping、thinking、working 等）、跟随鼠标的弹簧都在 disc 里，看得见时一动就重画。代价没量（`HANDOFF.md`）。

**缓动：**

- 正弦：`CAMediaTimingFunction(controlPoints: 0.37, 0, 0.63, 1)`。
- 弹簧用感知时长 response 和阻尼比 ζ 描述，换成 `CASpringAnimation`：mass 1，stiffness = (2π / response)²，damping = 4π · ζ / response，duration = settlingDuration。

### 换造型

所有部分一起补间，起点都从呈现层（`presentation()`）取，换到一半再换也接得上：

| 部分 | 补间 |
|---|---|
| 眼形 | 逐点变形（§3），0.38s，正弦 |
| 身体渐变 | 颜色过渡，0.4s，正弦 |
| 头的朝向 | 弹簧转到新造型的朝向，response 0.5、ζ 0.75 |
| 旧装饰 | 缩小到 0.4 并淡出，0.18s，ease-in，播完拿掉 |
| 新装饰 | 延迟 0.1s 弹出：弹簧放大 0.4 → 1（response 0.38、ζ 0.6），同时 0.16s 淡入（照 SF Symbols 的 Replace 效果，[WWDC23 10258](https://developer.apple.com/videos/play/wwdc2023/10258/)） |
| 常驻节奏 | 新造型的循环延迟 0.4s 起播 |
| 进 danger | 横向抖三下、逐次衰减：0 → 1.2 → −1 → 0.7 → −0.4 → 0 单位，关键帧在 0、0.075、0.15、0.225、0.3、0.45s |
| 进 finished | 播一次「完成跳转」（见下面的动作表） |
| 进 working | 播一次「点头」 |

旧造型的循环撤掉时补间收尾：从屏幕上的样子用 0.25s 正弦回到静止值，不一下子跳回 0。

### 常驻节奏

循环用 `CAKeyframeAnimation`，`repeatCount = .infinity`，最后一个关键帧的时刻就是周期；`timeOffset` = 相位，从换造型那一刻（加 0.4s 延迟）起播，起步无缝。表里「值」是叠加量（additive），除非写明是绝对值。头的角度用度；装饰的 rotation 用弧度。

**身体和头：**

| 造型 | 节奏 |
|---|---|
| 全部 | 呼吸：body 以身体底部为锚点，scaleY +0.03、scaleX −0.01，周期 4.6s，正弦往返；睡着时周期 6s、scaleY +0.045 |
| 睁眼的造型（idle、thinking、working、longTurn、question、approval、offline、mismatch、stale、shielded） | 眨眼：眼形补间成一条线再回来，闭 60ms、睁 140ms；间隔 2.5–6s 随机，15% 连眨两次（沿用 2a 的 `IdleDirector`，不用原型的固定 4.2s） |
| sleeping | pitch 0 → −4° → 0，周期 6s |
| thinking | yaw 0 → −8° → 0，周期 3.6s（慢慢左右琢磨） |
| working | yaw −7° → 7°（0.9s）→ −7°（0.25s）→ 停 0.25s，周期 1.4s，相位 0.45s（像一行行读字：慢慢扫过去，快速回行首） |
| longTurn | 同 working 但更快：扫 0.6s、回 0.2s、停 0.2s，周期 1.0s，相位 0.3s |
| dizzy | roll 0 → 6° → 0 → −6° → 0，周期 2.4s（摆锤） |
| offline | yaw 0 → −25°（0.5s）停到 1.2s → 25°（1.8s）停到 2.5s → 0（3.0s）停到 3.6s（左右找信号） |

**装饰：**

| 造型 | 节奏 |
|---|---|
| sleeping | 三个 Z 依次冒出、上浮、放大、淡出，每秒一个：周期 3s，第 i 个相位 (3 − i) mod 3 秒；上浮 −2 单位（ease-out）；x 0 → 0.5 → 0；scale −0.4 → 0（0.6s）→ +0.15；不透明度（绝对值）0 → 1（0.4s）→ 1（2.2s）→ 0 |
| thinking | 整朵云（全部部件）上下浮 0.5 单位，周期 2.4s；三个亮点依次亮：不透明度（绝对值）0 → 1 → 0（各 0.2s），周期 1.2s，相邻错开 0.2s |
| question | 气泡和 ? 上下浮 0.6 单位，周期 2s；? 每 2s 晃一下：rotation 0 → 0.2 → −0.2 → 0.1 → 0（0.48s 内） |
| finished | 大星慢转 90°（2.4s，线性）并一闪：scale +0.18（0.6s 到顶，1.2s 回落），周期 2.4s；小星和它错拍：不透明度 0.6 → 1 → 0.25 → 0.6，周期 2.4s，相位 1.2s |
| longTurn | 汗珠滑下来、淡出：下移 1.6 单位（1.6s，ease-in）；不透明度 0 → 1（0.2s）→ 1（1.3s）→ 0（1.6s），周期 2s |
| approval | 招手两下，停一会儿：绕手腕 rotation 0 → 0.3 → −0.15 → 0.3 → 0（0.8s 内），周期 2.4s |
| error | × 晃一下：rotation 0 → 0.2 → −0.2 → 0.1 → 0（0.32s 内），周期 2.6s |
| offline | 信号从里到外依次亮起又暗下去：点、小弧、大弧的不透明度（绝对值）0.25 → 1（0.3s）→ 0.25（0.9s），周期 2.4s，相邻错开 0.3s；斜杠不动 |
| mismatch | ▲! 连闪两下：scale +0.12，0.2s 一下，周期 2.6s |
| stale | 沙漏停一会儿、翻过来，再停、再翻：rotation 0（停到 1.2s）→ π（1.7s）停到 2.9s → 2π（3.4s） |
| danger | 两个 ! 轮流跳，像警报：上移 0.9 单位（0.12s 上、0.12s 下），周期 0.9s，第二个错开 0.24s |
| shielded | 每 3s 锁「咔哒」一下：锁梁下移 0.5 单位、锁身和锁孔 scale −0.06（0.12s 到位、0.3s 回来） |

### 动作

动作叠加在造型朝向和跟随鼠标之上（additive），关键帧之间用正弦。关键帧写成 时刻 s：yaw° / pitch° / roll° / dy（画布单位，负 = 向上），没写的分量是 0。

| 动作 | 关键帧 |
|---|---|
| 左右转圈 | 0：0；0.9：yaw 360 |
| 上下翻圈 | 0：0；0.9：pitch 360 |
| 东张西望 | 0：0；0.4：yaw −35；0.9：yaw −35；1.5：yaw 35；2.0：yaw 35；2.4：0 |
| 点头 | 0：0；0.18：pitch −18；0.38：0；0.55：pitch −10；0.75：0 |
| 歪头 | 0：0；0.35：roll 14；1.4：roll 14；1.7：0 |
| 摇头 | 0：0；0.15：yaw −22；0.35：yaw 22；0.52：yaw −14；0.66：yaw 8；0.78：0 |
| 抬头看天 | 0：0；0.45：pitch 35；1.5：pitch 35；1.9：0 |
| 低头看脚 | 0：0；0.45：pitch −35；1.5：pitch −35；1.9：0 |
| 侧身 90° | 0：0；0.5：yaw 90；1.3：yaw 90；1.7：0 |
| 好奇歪看 | 0：0；0.4：yaw 30 / pitch 12 / roll −10；1.4：同左；1.8：0 |
| 完成跳转 | 0：0；0.12：dy 1；0.4：yaw 180 / dy −4；0.67：yaw 360；0.8：yaw 360 |

**空闲小动作**：只在 idle 造型、并且鼠标停下超过 4s（注视已经回正）时做；每 8–20s 一个，不连续重复同一个。东张西望、点头、歪头、摇头、抬头看天、低头看脚、侧身 90°、好奇歪看等概率；左右转圈、上下翻圈各 5%。

### 跟随鼠标

- 每只盾盾按鼠标相对它自己身体圆心的位移算（左耳和面板里的不会同时看得见）：yaw = 25° × clamp(dx / 400, −1, 1)，pitch = 20° × clamp(dy / 400, −1, 1)，dx 向右为正、dy 向上为正。两轴各自线性，超过 400pt 就停在最大角度，不跳回正。
- 目标取整到 0.5°，变了才提交；弹簧 response 0.3、ζ 0.85，从呈现层的当前值起。
- 鼠标停 4s 后慢慢回正，0.8s 正弦（2a 的规则）。
- 只有睁眼的造型（眨眼那一行列出的）看鼠标。设置里可关（`config.json` 的 `mascotFollowsMouse`，默认开）。
- 鼠标到刘海上时「探头」：scale 1.06（弹簧 response 0.35、ζ 0.6），眼睛放大 1.1（眼形 0.25s 补间过去）。和跟随鼠标一样，只有睁眼的造型做，关掉「跟随鼠标」也不做。

### 收起与展开

- 黑色形状：收起是刘海 + 左右各 44 的耳朵，展开长成面板；两种状态用同一种画法（上沿直、下沿两个圆角，收起 r 8、展开（面板、卡片）r 28），路径结构一致才能补间。弹簧（用户 10-30 定，照实机已调好的手感；都在 `Common.swift` 的 `NotchSpring`）：展开和弹卡（包括卡换卡、面板换卡）response 0.5、ζ 0.7；收起 response 0.38、ζ 0.88；卡片放完、鼠标还在刘海上回到面板，以及面板行数变化，用 response 0.42、ζ 0.84。
- **盾盾是同一个角色**：左耳那只就是面板里的 32pt 盾盾缩到 20pt，展开时用弹簧移动、放大到面板里的位置，收起时反向。和形状用同一组弹簧，同步到位（用户 10-29）。补间时不重建图层（重建会重播进场、断掉循环相位）。所以左耳的 mood 装饰是 large 版缩小来的（多第三个 Z 和气泡里的 ?），不另画 20pt 版。
- 右耳和面板右上的出口徽章是同一个位置的两种样子：展开时右耳淡出、徽章从 0.4 倍放大淡入，跟着形状的弹簧移到面板右上；收起时反过来。
- 卡片形态时盾盾飞到卡片左侧（32pt），换成卡片的造型，告示画回来；右边一组淡出（`docs/ui.md`「卡片」）。透明的那组停掉动画（`MascotLayerView.playing`），因为窗口的遮挡状态看不出 SwiftUI 的透明度（CLAUDE.md「看不见就不调度」）。

### 减弱动态效果

不位移、不缩放、不旋转：造型的静止朝向直接设值、不补间，动作和跟随鼠标都不做；颜色和眼形 0.15s 淡入淡出；只保留眨眼；装饰静止，只有不透明度的闪烁（三蓝点、思考的点、断网信号）保留。展开、收起、弹卡时形状照常变，盾盾和右耳 / 徽章不飞：换形态时换一个新视图，旧的原地淡出，新的在新位置淡入。

### 性能验收

刘海机型 120Hz 屏，收起空闲 60s，App CPU 平均 < 0.5%；鼠标持续移动 60s < 3%。用 `top -l 70 -s 1 -pid <pid>` 测，结果写进提交说明。
